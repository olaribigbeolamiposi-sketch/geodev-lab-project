# Mapping Schools in Lagos Mainland LGA

A GeoDev Lab Africa project showing where schools recorded in OpenStreetMap are located within Lagos Mainland Local Government Area, Lagos State, Nigeria.

## Project Question

Where are the schools recorded in OpenStreetMap located within Lagos Mainland LGA?

## Planned Output

An interactive map where users can click school locations to view their names and other available details.

## Data Sources

- School records: [Nigeria Education Facilities — OpenStreetMap via HDX](https://data.humdata.org/dataset/hotosm_nga_education_facilities)
- LGA boundaries: [Nigeria Subnational Administrative Boundaries — HDX](https://data.humdata.org/dataset/cod-ab-nga)

## Current Progress

Week 1: Project planning and data checks.

- Downloaded both datasets.
- Confirmed that the boundary dataset includes Lagos Mainland.
- Identified 35 education records labelled Lagos Mainland, including 28 tagged as schools.
- Added the project brief.

These counts are preliminary. Records will be reviewed for missing names, incorrect classifications, and location accuracy. OpenStreetMap may not include every school.
